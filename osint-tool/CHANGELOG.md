# سجل التغييرات (Changelog)

جميع التغييرات المهمة في هذا المشروع سيتم توثيقها في هذا الملف.

التنسيق مبني على [Keep a Changelog](https://keepachangelog.com/ar/1.0.0/)،
وهذا المشروع يلتزم بـ [Semantic Versioning](https://semver.org/lang/ar/).

## [1.0.0] - 2024-12-03

### إضافات (Added)

#### الميزات الأساسية
- ✨ واجهة مستخدم رسومية كاملة باستخدام Electron
- 🔍 البحث عن الحسابات الاجتماعية عبر 15+ منصة
- ⚠️ فحص التسريبات الأمنية (محاكاة)
- 🌐 تحليل معلومات النطاقات (WHOIS)
- 📊 شبكة علاقات تفاعلية بسيطة
- 📋 تقارير شاملة ومنظمة

#### قاعدة البيانات
- 💾 قاعدة بيانات SQLite محلية
- 📁 جداول منظمة للأشخاص والحسابات والتسريبات والنطاقات
- 🔗 نظام علاقات متقدم (Graph Edges)
- 📝 سجلات مفصلة لجميع العمليات

#### وحدات جمع البيانات
- 👥 SocialMediaCollector - البحث عن الحسابات الاجتماعية
- 🔓 BreachCollector - فحص التسريبات
- 🌍 WhoisCollector - تحليل النطاقات
- 🧩 BaseCollector - فئة أساسية قابلة للتوسع

#### محرك التحليل
- 🧠 خوارزمية حساب التشابه بين الحسابات
- 📈 تقييم مستوى الثقة
- 🔗 بناء شبكة العلاقات (Graph)
- 📊 تحليل الأنماط الزمنية
- 📄 توليد تقارير شاملة

#### الواجهة
- 🎨 تصميم عصري بألوان داكنة
- 📱 واجهة سهلة الاستخدام
- 🔄 تبويبات متعددة لعرض النتائج
- 📊 بطاقات ملخصة للإحصائيات
- 📝 عرض السجلات بشكل منظم
- ⚙️ صفحة إعدادات

#### التوثيق
- 📖 README شامل بالعربية
- 📝 دليل المساهمة (CONTRIBUTING.md)
- 📜 رخصة MIT
- 📋 سجل التغييرات (CHANGELOG.md)

### الميزات التقنية
- ⚡ استخدام Electron لبناء تطبيق سطح مكتب
- 🔧 Node.js كبيئة تشغيل
- 📦 better-sqlite3 لقاعدة البيانات
- 🌐 axios للطلبات HTTP
- 🔍 cheerio لتحليل HTML
- 🎯 معمارية وحدية قابلة للتوسع

### الأمان والخصوصية
- 🔒 جميع البيانات محلية
- 🚫 لا يتم إرسال أي بيانات لخوادم خارجية
- ⚖️ تحذيرات قانونية وأخلاقية واضحة
- 📋 رخصة مفتوحة المصدر (MIT)
