### 2. جميع عوامل Google المتقدمة 

```
 site:        - البحث في موقع محدد
 filetype:    - نوع الملف
 intitle:     - في العنوان
 inurl:       - في الرابط
 intext:      - في النص
 AND/OR/-     - العوامل المنطقية
 " "          - مطابقة تامة
 *            - Wildcard
 ( )          - تجميع
```

### 3. التصنيف الذكي 

كل نتيجة يتم تصنيفها تلقائياً:
- **الفئة**: social_media, professional, leak, forum, document

- **المنصة**: استخراج تلقائي
- **نوع الملف**: استخراج تلقائي

##  أمثلة على الاستعلامات المولدة

### استعلامات أساسية
```
"John Smith"
"John Smith" "New York"
"John Smith" AND "Software Engineer"
"John" "Smith"
```

### البحث في المنصات الاجتماعية
```
site:facebook.com "John Smith"
site:twitter.com "johnsmith"
site:instagram.com intitle:"John Smith"
site:linkedin.com "john.smith@example.com"
```

### البحث عن الوثائق
```
"John Smith" (CV OR resume) filetype:pdf
"John Smith" filetype:docx
"john.smith@example.com" filetype:pdf
```

### البحث في مواقع التسريبات
```
site:pastebin.com "john.smith@example.com"
"john.smith@example.com" (leak OR breach OR dump)
```

### استعلامات مركبة
```
"John Smith" AND "john.smith@example.com"
("John Smith" OR "johnsmith") AND "New York"
"John Smith" -site:linkedin.com
```

### Wildcard للبريد الإلكتروني
```
"john.smith"*@example.com
"john.smith"*@*
*@example.com
```
