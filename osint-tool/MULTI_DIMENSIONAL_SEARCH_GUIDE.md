## ⚖️ نظام الأوزان

### مبدأ العمل

كل معطى له **وزن (0-1)** يعكس أهميته في تحديد الهوية:

```
الوزن العالي (0.8-1.0) = معرّف فريد أو شبه فريد
الوزن المتوسط (0.5-0.7) = معلومة مهمة لكن ليست فريدة
الوزن المنخفض (0.2-0.4) = معلومة مساعدة فقط
```

### مثال على الحساب

```javascript
المعطيات المدخلة:
- البريد: ahmed@example.com (وزن 0.95)
- الاسم: أحمد محمد (وزن 0.80)
- المدينة: الرياض (وزن 0.45)

المرشح:
- البريد: ahmed@example.com (مطابقة 100%)
- الاسم: أحمد محمد (مطابقة 100%)
- المدينة: الرياض (مطابقة 100%)

الحساب:
= (0.95 × 1.0) + (0.80 × 1.0) + (0.45 × 1.0)
= 0.95 + 0.80 + 0.45
= 2.20

الدرجة النهائية:
= 2.20 / (0.95 + 0.80 + 0.45)
= 2.20 / 2.20
= 1.00 (100%)
```

## 🧠 خوارزمية المطابقة

النظام يستخدم **6 خوارزميات مختلفة** حسب نوع المعطى:

### 1. المطابقة التامة (Exact Match)

**الاستخدام**: البريد، الهاتف، اسم المستخدم، تاريخ الميلاد

```
إذا كانت القيمتان متطابقتان تماماً → 100%
وإلا → حساب المسافة (Levenshtein Distance)
```

**مثال**:
```
"ahmed@example.com" vs "ahmed@example.com" → 100%
"ahmed@example.com" vs "ahmad@example.com" → 94%
```

### 2. مطابقة الأسماء (Name Matching)

**الاستخدام**: الاسم الكامل، الاسم الأول، اسم العائلة

```
1. تقسيم الاسم إلى أجزاء
2. حساب التطابق لكل جزء
3. النتيجة = عدد الأجزاء المتطابقة / إجمالي الأجزاء
```

**مثال**:
```
"أحمد محمد" vs "أحمد محمد علي"
→ 2 أجزاء متطابقة من 3 = 67%

"John Smith" vs "John Michael Smith"
→ 2 أجزاء متطابقة من 3 = 67%
```

### 3. المطابقة الجزئية (Partial Match)

**الاستخدام**: الموقع، المدينة، الجامعة، الشركة

```
إذا كانت إحدى القيمتين تحتوي الأخرى → 80%
وإلا → حساب الكلمات المشتركة (Jaccard Similarity)
```

**مثال**:
```
"الرياض" vs "مدينة الرياض" → 80%
"جامعة الملك سعود" vs "جامعة الملك عبدالعزيز" → 50%
```

### 4. المطابقة الدلالية (Semantic Match)

**الاستخدام**: مجال العمل، المسمى الوظيفي، المؤهل

```
1. البحث في قاموس المرادفات
2. إذا وجدت مرادفات → 85%
3. وإلا → مطابقة جزئية
```

**مثال**:
```
"مهندس برمجيات" vs "مطور برامج" → 85%
"developer" vs "programmer" → 85%
"manager" vs "director" → 85%
```

### 5. مطابقة المجموعات (Set Matching)

**الاستخدام**: المهارات، الاهتمامات، اللغات

```
Jaccard Similarity = التقاطع / الاتحاد
```

**مثال**:
```
"Python, Java, C++" vs "Python, JavaScript, C++"
→ التقاطع = {Python, C++} = 2
→ الاتحاد = {Python, Java, C++, JavaScript} = 4
→ النتيجة = 2/4 = 50%
```

### 6. مسافة Levenshtein (String Distance)

**الاستخدام**: افتراضي لجميع الأنواع الأخرى

```
1. حساب عدد التعديلات المطلوبة (إضافة، حذف، استبدال)
2. النتيجة = 1 - (التعديلات / أطول نص)
```

**مثال**:
```
"ahmed" vs "ahmad"
→ تعديل واحد (e → a)
→ النتيجة = 1 - (1/5) = 80%
```

## 💻 الاستخدام البرمجي

### التثبيت

```bash
cd /home/ubuntu/osint-tool
npm install
```

### الاستخدام الأساسي

```javascript
const MultiDimensionalSearchEngine = require('./src/modules/multiDimensionalSearch');
const Database = require('./src/database/schema');

// تهيئة
const db = new Database('./data/osint.db');
const searchEngine = new MultiDimensionalSearchEngine(db, {
  sherlock: sherlockCollector,
  maigret: maigretCollector,
  holehe: holeheCollector,
  hibp: hibpCollector,
  googleDorks: dorksCollector
});

// معطيات البحث
const searchCriteria = {
  fullName: 'أحمد محمد',
  email: 'ahmed@example.com',
  username: 'ahmed_dev',
  phone: '+966501234567',
  location: 'الرياض',
  university: 'جامعة الملك سعود',
  occupation: 'مهندس برمجيات'
};

// البحث
const results = await searchEngine.search(searchCriteria, {
  maxCandidates: 100,
  minScore: 0.30,
  enableAllCollectors: true,
  deepSearch: false
});

// النتائج
console.log(`النتائج: ${results.results.strong.length} قوي`);
console.log(`التقرير:`, results.report);
```
