# 🚀 دليل البدء السريع

دليل سريع لتشغيل أداة OSINT Tool في دقائق معدودة.

## المتطلبات الأساسية

قبل البدء، تأكد من تثبيت:
- Node.js (الإصدار 14 أو أحدث)
- npm (يأتي مع Node.js)

للتحقق من التثبيت:
```bash
node --version
npm --version
```

## خطوات التشغيل السريع

### 1. تحميل المشروع

```bash
# إذا كان المشروع على GitHub
git clone <repository-url>
cd osint-tool

# أو إذا كان لديك ملف مضغوط
unzip osint-tool.zip
cd osint-tool
```

### 2. تثبيت المكتبات

```bash
npm install
```

هذا سيقوم بتثبيت جميع المكتبات المطلوبة:
- electron
- better-sqlite3
- axios
- cheerio

### 3. تشغيل التطبيق

```bash
npm start
```

سيفتح التطبيق تلقائياً في نافذة جديدة.

## الاستخدام الأساسي

### إجراء بحث جديد

1. **افتح التطبيق**
   - سيظهر لك الشاشة الرئيسية

2. **أدخل المعلومات**
   - الاسم الكامل (اختياري)
   - البريد الإلكتروني (مطلوب)
   - اسم المستخدم (مطلوب)

3. **ابدأ البحث**
   - انقر على زر "بدء التحقيق"
   - انتظر حتى تكتمل العملية (قد تستغرق دقيقة أو دقيقتين)

4. **استعرض النتائج**
   - ستظهر النتائج في تبويبات متعددة:
     - نظرة عامة
     - الحسابات الاجتماعية
     - التسريبات
     - النطاقات
     - شبكة العلاقات
     - السجلات

### عرض التحقيقات السابقة

1. انقر على "التحقيقات" من القائمة الجانبية
2. اختر التحقيق الذي تريد عرضه
3. ستظهر جميع النتائج المحفوظة

## نصائح مهمة

### ✅ أفضل الممارسات

- **استخدم بريد إلكتروني حقيقي**: للحصول على نتائج أفضل
- **اسم مستخدم شائع**: جرب أسماء مستخدم يستخدمها الشخص فعلياً
- **انتظر اكتمال البحث**: لا تغلق النافذة أثناء البحث
- **راجع السجلات**: للحصول على تفاصيل عملية البحث

### ⚠️ تحذيرات

- **الاستخدام القانوني فقط**: لا تستخدم الأداة لأغراض غير قانونية
- **احترم الخصوصية**: ابحث فقط عن معلومات عامة
- **البيانات محلية**: جميع البيانات تُخزن على جهازك فقط

### 🔧 حل المشاكل الشائعة

**المشكلة**: التطبيق لا يفتح
```bash
# جرب إعادة تثبيت المكتبات
rm -rf node_modules
npm install
npm start
```

**المشكلة**: خطأ في قاعدة البيانات
```bash
# احذف قاعدة البيانات وأعد التشغيل
rm -rf data/
npm start
```

**المشكلة**: لا توجد نتائج
- تأكد من اتصالك بالإنترنت
- جرب اسم مستخدم مختلف
- راجع السجلات لمعرفة الأخطاء

## الإعدادات المتقدمة

### إضافة مفاتيح API

1. انقر على "الإعدادات" من القائمة
2. أدخل مفاتيح API (اختياري):
   - HaveIBeenPwned API Key
3. احفظ الإعدادات

### تفعيل التسجيل المفصل

1. اذهب إلى الإعدادات
2. فعّل "تسجيل مفصل"
3. احفظ الإعدادات
