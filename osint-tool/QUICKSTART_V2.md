# 🚀 دليل التشغيل السريع - OSINT Tool v2.0

## التثبيت السريع

### 1. تثبيت المتطلبات الأساسية

```bash
# تثبيت Node.js dependencies
cd osint-tool
npm install

# تثبيت Python tools
sudo pip3 install sherlock-project maigret holehe exifread pillow weasyprint

# (اختياري) تثبيت Tor
sudo apt-get install tor
sudo systemctl start tor
```

### 2. تشغيل التطبيق

```bash
# وضع التطوير
npm run dev

# وضع الإنتاج
npm start
```

## الاستخدام السريع

### 1. بدء تحقيق جديد

1. افتح التطبيق
2. انقر على "تحقيق جديد"
3. أدخل المعلومات المتوفرة:
   - الاسم الكامل
   - البريد الإلكتروني
   - اسم المستخدم
   - رقم الهاتف
4. اختر الأدوات:
   - ✅ Sherlock (سريع - موصى به)
   - ✅ Holehe (للبريد)
   - ✅ HIBP (للتسريبات)
   - ✅ Google Dorks
   - ⏱️ Maigret (معمق - يستغرق وقتاً)
5. انقر "بدء التحقيق"

### 2. عرض النتائج

- **الحسابات الاجتماعية**: قائمة بجميع الحسابات المكتشفة
- **التسريبات**: قائمة التسريبات الأمنية
- **الرسم البياني**: شبكة العلاقات التفاعلية
- **السجلات**: تفاصيل كل خطوة

### 3. تصدير التقرير

1. انقر على "تصدير"
2. اختر الصيغة:
   - JSON (للمطورين)
   - CSV (للتحليل)
   - PDF (للمشاركة)
3. احفظ الملف

## الميزات المتقدمة

### تحليل صورة

```
1. اذهب إلى "تحليل الصور"
2. أدخل URL الصورة أو ارفعها
3. انتظر التحليل
4. اعرض:
   - بيانات EXIF (GPS, Camera, Date)
   - نتائج البحث العكسي
```

### تحليل نص

```
1. اذهب إلى "تحليل النصوص"
2. الصق النص
3. انتظر التحليل
4. اعرض البصمة الأسلوبية
```

### تفعيل Tor

```
1. اذهب إلى "الإعدادات"
2. فعّل "استخدام Tor"
3. انتظر الاتصال
4. جميع الطلبات ستمر عبر Tor
```

## نصائح سريعة

### للحصول على أفضل النتائج

1. **استخدم معلومات دقيقة**: كلما كانت المعلومات أدق، كانت النتائج أفضل
2. **ابدأ بـ Sherlock**: سريع ويغطي 400+ موقع
3. **استخدم Maigret للبحث المعمق**: إذا كان لديك وقت
4. **فعّل Tor للخصوصية**: خاصة للتحقيقات الحساسة
5. **صدّر النتائج بانتظام**: احتفظ بنسخة احتياطية

### تجنب المشاكل

1. **لا تبحث بسرعة كبيرة**: قد تُحظر
2. **استخدم Cache**: لتقليل الطلبات المكررة
3. **شفّر قاعدة البيانات**: للبيانات الحساسة
4. **امسح Cache بانتظام**: لتوفير المساحة

## الأوامر المفيدة

```bash
# تحديث الأدوات
sudo pip3 install --upgrade sherlock-project maigret holehe

# مسح Cache
rm -rf cache/*

# نسخ احتياطي لقاعدة البيانات
cp data/osint.db data/osint.db.backup

# تشفير قاعدة البيانات (من داخل التطبيق)
# الإعدادات > الأمان > تشفير قاعدة البيانات
```

## استكشاف الأخطاء السريع

| المشكلة | الحل |
|---------|------|
| Sherlock لا يعمل | `sudo pip3 install --upgrade sherlock-project` |
| Tor لا يتصل | `sudo systemctl restart tor` |
| فشل تصدير PDF | `sudo apt-get install wkhtmltopdf` |
| خطأ في EXIF | `sudo pip3 install exifread pillow` |
| بطء التطبيق | امسح Cache، أغلق الأدوات غير المستخدمة |
