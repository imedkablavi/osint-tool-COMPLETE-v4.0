#  دليل الاختبار - OSINT Tool v2.0

هذا الدليل يساعدك على اختبار جميع ميزات الأداة بنفسك.

---

##  التحضير

### 1. تثبيت المتطلبات

```bash
# Node.js dependencies
npm install

# Python tools
sudo pip3 install sherlock-project maigret holehe exifread pillow weasyprint

# (اختياري) Tor
sudo apt-get install tor
sudo systemctl start tor
```

### 2. تشغيل التطبيق

```bash
npm start
```

---

## 1 اختبار Sherlock

### الخطوات:
1. افتح التطبيق
2. اذهب إلى "تحقيق جديد"
3. أدخل اسم مستخدم معروف (مثل: `google`, `microsoft`, `apple`)
4. اختر "Sherlock" من قائمة الأدوات
5. انقر "بدء البحث"

### النتيجة المتوقعة:
-  يجب أن تظهر 40+ حساب
-  الوقت: أقل من دقيقة
-  الروابط: قابلة للنقر

---

## 2 اختبار Maigret

### الخطوات:
1. استخدم نفس اسم المستخدم
2. اختر "Maigret"
3. انقر "بدء البحث"
4. **انتظر**: قد يستغرق 5-10 دقائق

### النتيجة المتوقعة:
-  نتائج أكثر من Sherlock
-  معلومات إضافية من الملفات الشخصية

---

## 3 اختبار Holehe

### الخطوات:
1. أدخل بريد إلكتروني (مثل: `test@gmail.com`)
2. اختر "Holehe"
3. انقر "بدء البحث"

### النتيجة المتوقعة:
-  قائمة بـ 120+ موقع
-  ألوان:
  -  أخضر = حساب موجود
  -  بنفسجي = لا يوجد حساب
  -  أحمر = rate limit

---

## 4 اختبار HaveIBeenPwned

### المتطلبات:
- API Key من https://haveibeenpwned.com/API/Key (مجاني)

### الخطوات:
1. احصل على API Key
2. أدخله في الإعدادات
3. أدخل بريد معروف بوجود تسريب
4. اختر "HIBP"
5. انقر "بحث"

### النتيجة المتوقعة:
-  قائمة بالتسريبات
-  تفاصيل كل تسريب
-  تاريخ التسريب

---

## 5 اختبار Google Dorks

### الخطوات:
1. أدخل بريد أو اسم
2. اختر "Google Dorks"
3. اختر القوالب المناسبة
4. انقر "بحث"

### النتيجة المتوقعة:
-  روابط Google مع dorks
-  نتائج من Pastebin, GitHub, LinkedIn, إلخ

---

## 6 اختبار تحليل الصور

### الخطوات:
1. اذهب إلى "تحليل الصور"
2. ارفع صورة أو أدخل URL
3. انقر "تحليل"

### النتيجة المتوقعة:
-  بيانات EXIF:
  - GPS (إن وجد)
  - الكاميرا
  - التاريخ والوقت
-  نتائج البحث العكسي (Google + Yandex)

### صور للاختبار:
- استخدم صور من هاتفك (عادة تحتوي EXIF)
- أو ابحث عن "sample image with exif data"

---

## 7 اختبار تحليل النصوص (Stylometry)

### الخطوات:
1. اذهب إلى "تحليل النصوص"
2. الصق نصين لنفس الكاتب
3. الصق نص ثالث لكاتب مختلف
4. انقر "تحليل"

### النتيجة المتوقعة:
-  بصمة أسلوبية لكل نص
-  نسبة التشابه بين النصوص
-  النصان الأولان: تشابه عالي (>70%)
-  النص الثالث: تشابه منخفض (<50%)

---

## 8 اختبار الرسم البياني

### الخطوات:
1. أنشئ تحقيقاً واجمع بيانات
2. اذهب إلى "الرسم البياني"
3. جرّب:
   - تكبير/تصغير (Zoom)
   - سحب العقد
   - النقر على العقد لعرض المعلومات
   - تغيير نوع التخطيط
   - استخدام الفلاتر

### النتيجة المتوقعة:
-  رسم تفاعلي
-  عقد ملونة حسب النوع
-  علاقات واضحة
-  إحصائيات مباشرة

---

## 9 اختبار Tor/Proxy

### الخطوات:
1. ثبّت Tor: `sudo apt-get install tor`
2. شغّل Tor: `sudo systemctl start tor`
3. في التطبيق، اذهب إلى "الإعدادات"
4. فعّل "استخدام Tor"
5. أعد البحث

### النتيجة المتوقعة:
-  جميع الطلبات تمر عبر Tor
-  IP مخفي
-  البحث قد يكون أبطأ

---

##  اختبار التصدير

### الخطوات:
1. بعد جمع البيانات
2. انقر "تصدير"
3. اختر الصيغة:
   - JSON
   - CSV
   - PDF
4. احفظ الملف

### النتيجة المتوقعة:

**JSON**:
-  ملف واحد
-  بنية منظمة
-  جميع البيانات

**CSV**:
-  4 ملفات (persons, accounts, breaches, relationships)
-  قابل للفتح في Excel
-  UTF-8 encoding

**PDF**:
-  تقرير احترافي
-  غلاف وملخص
-  جداول ورسم بياني

## 11 اختبار Cache

### الخطوات:
1. ابحث عن نفس الشخص مرتين
2. لاحظ الوقت

### النتيجة المتوقعة:
-  المرة الأولى: بطيئة
-  المرة الثانية: سريعة جداً (من Cache)

---

## 12 اختبار التشفير

### الخطوات:
1. اذهب إلى "الإعدادات"
2. فعّل "تشفير قاعدة البيانات"
3. أدخل كلمة مرور
4. أغلق التطبيق
5. أعد فتحه
6. أدخل كلمة المرور

### النتيجة المتوقعة:
-  قاعدة البيانات مشفرة
-  لا يمكن فتحها بدون كلمة المرور
