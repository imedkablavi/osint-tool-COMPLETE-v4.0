OSINT Tool v4.1

مساحة عمل محلية لجمع وربط معلومات من مصادر عامة ضمن استخدامات مشروعة.

مبادئ المنتج

  • Local-first case storage
  • Live data sources only in the active workflow
  • Explicit source attribution
  • Isolated Electron renderer

حدود النتائج

تطابق اسم مستخدم أو عنوان URL لا يثبت الهوية. يجب التحقق البشري من النتائج قبل استخدامها في قرار أو تقرير.
